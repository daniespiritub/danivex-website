# Account surface review

Review performed in-thread using the degraded reviewer/documenter procedure because
no subagent capability was available. This is not an independent external review.
Scope: existing-world extension, functional account UI, not a new visual identity.

## Persistence

Existing PRODUCT.md / DESIGN.md retained. Public identity, logo, hero, Companion
and game tools are preserved. No new visual assets or generative design claims.

## Fidelity

- TYPE: compact operational headings/body inherited from existing typography.
- MATERIAL: flat controls and lists, actual existing logo; no fabricated 3D/raster.
- GROUND: existing dark page background, restrained red primary actions and gold links.
- Mobile: horizontal account navigation, usable form widths, no document overflow.
- Initial gray primary action was corrected to the existing red family and recaptured.

## Ceiling

Operate surface deliberately prioritizes readable forms/lists over decorative cards
or a marketing hero. Existing public-page display typography remains unchanged.

## Material fixes

Resolved primary action contrast/identity mismatch. Screenshots under
.qa/account-surface show the correction. No runtime service availability is inferred
from fixture visuals. Hosted auth/provider behavior remains an activation gate.

## Keep

Preserve public DaniVex identity, plain private lists, labeled controls and honest
empty/unavailable states. Disposition: ship UI under disabled feature gates only.
No changes to incumbent design-system files; existing public language coverage is
ES/PT/EN, while the new account surface supports ES/EN/IT/PT.
