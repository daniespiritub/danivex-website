# DaniVex

## Platform

web

## Users

Free Fire players configuring Android, iPhone or tablets, looking up public
player profiles, and using DaniVex Windows software. Spanish, Portuguese and
English audiences use the home on mobile and desktop.

## Product Purpose

A gamer tools platform: sensitivity generation, Player Scanner, DaniVex
Mobilador downloads and community. Preserve actual functionality and data.

## Capabilities and Constraints

React 19 / Vite SPA, Vercel serverless APIs, Redis and provider aggregation.
Routes: /, /player-scanner, /cuenta/:uid.html and legacy scanner redirects.
No new data providers, private API access or backend rights changes in this work.
The sensitivity catalog stays lazy; ranking rules and calculation stay intact.
Only actual releases, fields and features may be advertised.
