# DaniVex Design

## Direction

The user delegates the visual choices in the supplied brief. Work directly in
the existing application. Seven grounded directions considered: launcher,
competitive setup bench, tournament broadcast, game library desk, hardware
catalog, tactical map, community feed. The selected game library desk combines
immediate tools, owned software and a small character sharing the workspace.
No invented statistics or unrelated visual narratives.

## System

Charcoal ground, off-white text, DaniVex red actions, restrained yellow details,
blue for information and green for community. Space Grotesk for headings,
Manrope for body; both local. Zero tracking, fixed type sizes at breakpoints.
Full-width section bands; content constrained to 1120px with clear dividers.
Controls use 6px corners; cards only for actual individual products or tools.

## Home

Brand name and concise purpose over the existing gaming background, real tool
shortcuts and a reserved small character anchor. Sensitivity remains accessible
directly below. Flat form columns and one clear result readout. Mobilador uses
the real full application screenshots with a functional screen selector.
Software downloads use a metadata row sourced from the existing release.

## Companion

One transparent lazy Three.js renderer. The rejected procedural model and its
fallback have been removed entirely, without recycling their geometry.
The replacement is a professional stylized young gamer, friendly dimensional face,
expressive eyelids/eyes/mouth, modeled fingers and sneakers, layered graphite
and violet clothing, subtle red/gold accents. GLB loader accepts named clips.
Controller and placement do not depend on the character asset. The character
adapts Blender Studio Snow v4 under CC BY 4.0 with public attribution. Fabric,
skin, eyes, modeled hair and rubber retain different material responses. Cuff
color is baked continuously; the white sole edge is split in the shoe geometry.
Facial morphs include relaxed mouth shapes rather than a fixed grin in every state.
Hero anchor, collision-free viewport gutters, reserved nav dock when no safe
space remains. Hide on mobile text entry and dialogs. Persist motion/minimize
preferences. Reduced motion and hidden-tab behavior stop the render loop.
Animate travel only when its full swept rectangle is free of protected content.

## Interaction

Native scroll; quiet hover feedback; a short arrival greeting is the primary
authored motion. No scroll hijacking, chat bubbles or autoplay sound. Use the
existing react-icons library. All secondary controls have accessible names,
visible focus and touch targets. Sections declare companion metadata.
